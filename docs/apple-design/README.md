# Reference Documentation — Apple Design & HIG

This directory centralizes research conducted on official Apple developer documentation, design resources (`Apple Design Resources`), Human Interface Guidelines (`HIG`), and licensing terms applied in the engineering of **Pencel** (a modern web graphic editor combining creative suite workflows with Apple design ergonomics).

## Document Index

1. [Consulted Sources & Methodology (`sources.md`)](./sources.md) — Auditable log of official Apple URLs, verification dates, DocC/HTML status, and explicit separation between official specs and web adaptations.
2. [PackageDescription: macOS Platform (`macos-platform.md`)](./macos-platform.md) — Technical analysis of `Platform.macOS` in Swift Package Manager.
3. [StoreKit: AppStore.Platform.macOS (`appstore-platform.md`)](./appstore-platform.md) — Technical analysis of `AppStore.Platform.macOS` in StoreKit.
4. [Human Interface Guidelines — Principles & Overview (`human-interface-guidelines.md`)](./human-interface-guidelines.md) — Core principles (_Purpose_, _Agency_, _Responsibility_) and _Designing for macOS_ desktop ergonomics.
5. [Apple Design Resources (`design-resources.md`)](./design-resources.md) — Survey of Figma/Sketch UI Kits, icon templates, fonts, and web licensing boundaries.
6. [Typography (`typography.md`)](./typography.md) — San Francisco and New York font families, licensing restrictions, and web-safe fallback typography stacks.
7. [Color & Appearance (`color-and-appearance.md`)](./color-and-appearance.md) — Dynamic semantic colors, WCAG contrast ratios, and Light/Dark mode parity.
8. [Layout & Spacing (`layout-and-spacing.md`)](./layout-and-spacing.md) — Visual hierarchy, desktop information density, optical alignment, toolbars, and inspector panels.
9. [Materials & Visual Effects (`materials-and-effects.md`)](./materials-and-effects.md) — Analysis of macOS Materials, Vibrancy, and Liquid Glass translated to modern CSS (`backdrop-filter`).
10. [Iconography & Licensing (`iconography.md`)](./iconography.md) — SF Symbols licensing boundaries and the `<Icon />` abstraction architecture using `lucide-react`.
11. [Accessibility (`accessibility.md`)](./accessibility.md) — WCAG AA contrast, keyboard navigation, accessible semantics, and `prefers-reduced-motion`.
12. [Motion & Interactions (`motion-and-interactions.md`)](./motion-and-interactions.md) — Micro-interactions, spatial coherence, and physics-based easing.
13. [Derived Design Decisions (`design-decisions.md`)](./design-decisions.md) — Consolidated synthesis of design system decisions implemented in Pencel.
