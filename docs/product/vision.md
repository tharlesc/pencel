# Product Vision — Pencel (`vision.md`)

**Pencel** is a modern, high-performance web graphics editor engineered for rapid, pixel-precise creation of digital creative assets:

- Instagram posts (`1080 × 1080 px` and portrait `1080 × 1350 px`).
- Stories and Reels covers (`1080 × 1920 px`).
- Web and social media banners (`1920 × 1080 px`).
- Digital promotional flyers (`1200 × 1600 px`).
- Multi-layer compositions blending typography, vector shapes, photography, and autonomous AI-generated elements.

---

## 1. Core Experience Pillars

1. **Modern Functional Ergonomics + Desktop Precision:** Combines the fast format-first workflow of modern web design tools with the visual serenity, typographic hierarchy, and ergonomic precision inspired by Apple's macOS Human Interface Guidelines (HIG).
2. **Proprietary Visual Identity:** Multi-layered neutral glass surfaces, tabular numeric typography, unified semantic iconography, and seamless Light/Dark themes that place user content at the center of attention.
3. **Evolutionary Architecture:** Clean separation between the pure domain document model (`@pencel/editor-core`), canvas adapter (`Fabric.js`), and React UI state, enabling continuous evolution without structural rewrites.
